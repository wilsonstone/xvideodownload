# X Video Download Helper

一个本地 Chrome 扩展示例：在 x.com / twitter.com 的视频右下角显示下载按钮，用于保存你自己拥有权利、已获授权，或依法允许保存的视频内容。

本项目不是 X / Twitter 的官方产品，也未与 X Corp. 关联、认可或赞助。

## 安装

1. 打开 Chrome，进入 `chrome://extensions/`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹：`/Users/wilsonstone/cc/xvideodownload`。

## 使用

打开 `https://x.com` 或 `https://twitter.com`，看到你有权保存的视频后，点击视频右下角的“下载”按钮。

## 技术说明

- 扩展会在浏览器本地运行，不需要独立服务器。
- 扩展只在 `x.com`、`twitter.com` 和 `video.twimg.com` 相关页面/资源上工作。
- 某些页面需要刷新一次后，扩展才能读取到当前页面已经加载的视频信息。
